- DATA DE ENVIO DO ENVELOPE
    - Para ser preenchido, é preciso preencher o Campo "modelo" com a opção "NOVO"
- DATA DE ENVIO BH
    - Campo para ser preenchido manualmente.
- DATA DO RECEBIMENTO EM BH
    - É preciso entrar na etapa "Aguardando Calce em BH"
- DATA DE ENVIO SUL
    - Campo para ser preenchido manualmente.
- DATA DO RECEBIMENTO NO SUL
    - Campo para ser preenchido manualmente.
- DATA DA APOVAÇÃO DO ENVELOPE
    - É preciso entrar na etapa "Envelope Aprovado" para ser preenchido
- DATA DA FINALIZAÇÃO DOS AJUSTES
    - Precisa entrar na etapa "Modelo Aprovado e Corrigido"
- DATA DA FICHA DE COMBINAÇÃO
    - Ao carregar imagem na Aba "Imagem" com a opção "04 - FICHA DE COMBINAÇÃO", quando card estiver na etapa "Modelo aprovado", mover card para a etapa "Ficha de Combinação Desenvolvida". Quando entrar nessa etapa a data é preenchida.
- DATA DE INICIO DO DESENVOLVIMENTO DA MAQUETE
    - É preciso entrar na etapa "Desenvolvendo desenho técnico"
- DATA DE FINALIZAÇÃO DA MAQUETE
    - É preciso entrar na etapa "Maquete Pronta"
- DATA DE APROVAÇÃO DO MODELO
    - É preciso preencher "Status do Calce 1" com Aprovado ou Aprovado com ressalvas, para ser preenchido.
- DATA FICHA CORRIGIDA
    - Precisa entrar na etapa "Ficha de Combinação desenvolvida e modelo corrigido"
